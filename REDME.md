
## 1. Difference between var, let and const

- **var** is old type variable in JavaScript. It can redeclare and also change value many time. Sometimes it create problem because of scope.  
- **let** is newer way to declare variable. It can change value but cannot redeclare in same block scope.  
- **const** use for fixed value. Once declare it cannot change again.  

## 2. What is the spread operator (...)

- Spread operator `(...)` use to expand values from array or object.  
- It help to combine or copy data easily.  

## 3. Difference between map(), filter(), and forEach()

- **map()** go through array and return new array after doing some change.  
- **filter()** also return new array but only the elements that match condition.  
- **forEach()** just loop through array but it not return new array.  

## 4. What is an arrow function?

- Arrow function is short syntax for writing function in JavaScript.  
- It make code smaller and more simple.  

## 5. What are template literals?

- Template literals is a way to write string using backtick (`).  
- It allow to put variable inside string easily.
